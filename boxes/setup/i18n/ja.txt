128	Windows と並べて
129	起動のたびに Shrimp か Windows を選びます。
130	プログラム
131	Windows の .exe ファイルはここでは動きません。プログラムは Shrimp Apps からインストールします。よく知られたアプリの多くには、同等のものがあります。
132	変更時のパスワード
133	プログラムのインストールや重要な設定の変更時には、パスワードを求められます。これは正常な動作で、コンピューターを守るためのものです。
134	あなたのファイル
135	ドキュメント、写真、ダウンロードは、ホーム フォルダーの「ファイル」アプリにあります。
136	Windows のドライブもそこにあります。
137	Panko
138	変更後に何かが動かなくなりましたか？ Panko なら、変更前の状態に戻せます。
139	Cocktail
140	更新、ドライバー、コーデックを 1 か所で管理できます。更新は再起動時にインストールされます。
141	クイック検索
142	Windows ロゴのある Super キーを押すと、プログラム、ファイル、設定を探せます。
143	ヘルプ
144	答えは、Shrimp のヘルプ ページ、GNOME や openSUSE のドキュメント、コミュニティのフォーラムで見つかります。
