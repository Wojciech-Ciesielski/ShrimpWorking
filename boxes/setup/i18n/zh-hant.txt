126	Shrimp 就是 Linux
127	Linux 是由世界各地的人們共同打造的免費系統，大多數伺服器和 Android 手機都運行在它之上。
128	與 Windows 並存
129	每次啟動時，你可以選擇進入 Shrimp 或 Windows。
130	程式
131	Windows 的 .exe 檔案無法在這裡執行。程式請從 Shrimp Apps 安裝，大多數知名應用程式都能在那裡找到替代品。
132	變更時需要密碼
133	安裝程式或變更重要設定時，系統會要求輸入你的密碼。這是正常的，可以保護你的電腦。
134	你的檔案
135	文件、照片和下載內容位於主資料夾中的「檔案」應用程式。
136	你也可以在那裡找到 Windows 磁碟機。
137	Panko
138	變更後有東西無法使用了嗎？在 Panko 中，你可以回到變更前的狀態。
139	Cocktail
140	更新、驅動程式和編解碼器集中在同一處。更新會在重新啟動時安裝。
141	快速搜尋
142	按下 Super 鍵（有 Windows 標誌的按鍵），即可尋找程式、檔案和設定。
143	說明
144	你可以在 Shrimp 說明頁面、GNOME 和 openSUSE 文件，以及社群論壇中找到答案。
